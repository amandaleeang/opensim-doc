# User / Resident Guide

This guide is for people who want to **visit** OpenSim worlds using a viewer.
You do not need to run a server to follow this guide.

## What you need

1. A **viewer** – we recommend [Firestorm](https://www.firestormviewer.org/), the most popular viewer for OpenSim.
2. An **account** on a grid (the grid operator gives you a first name, last name, and password), **or** the estate owner account created when you (or a friend) start your own simulator.
3. The **login URI** of the grid you want to join (for example `login.osgrid.org` for OSGrid, or `http://127.0.0.1:9000` for a simulator running on your own machine).
